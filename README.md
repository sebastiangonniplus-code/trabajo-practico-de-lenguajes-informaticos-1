# Puerto Abisal

Sitio web turístico y de información general sobre la ciudad costera ficticia **Puerto Abisal**, desarrollado como Trabajo Práctico Grupal para la asignatura **Lenguajes Informáticos 1** de la **Universidad Nacional de Hurlingham (UNAHUR)** (2026).

## Información académica

- **Institución:** Universidad Nacional de Hurlingham (UNAHUR) — Instituto de Tecnología e Ingeniería
- **Materia:** Lenguajes Informáticos 1 (2026)
- **Proyecto:** Trabajo Práctico Grupal — Sitio web multipágina (HTML5, CSS3, Bootstrap 5 y JavaScript)
- **Integrantes del equipo:** Sebastián Goñi, Julia Marra, Florencia Petruccelli, Joaquin Sosa y Lucas Romero

## Estructura del proyecto

```text
trabajo-practico-de-lenguajes-informaticos-1/
├── index.html          # Página de inicio con bienvenida y accesos directos
├── ciudad.html         # Historia, identidad, sectores, datos principales y costumbres
├── lugares.html        # Guía de lugares de interés (Faro, Acuario, Distrito Coral)
├── actividades.html    # Índice y tarjetas de actividades turísticas y eventos
├── contacto.html       # Datos de contacto y formulario interactivo de consultas
├── css/
│   └── estilos.css     # Variables CSS, estilos propios, posicionamiento y modo claro
├── js/
│   └── main.js         # Cambio de tema con localStorage y validación de formulario
└── Imagenes/           # Recursos gráficos de las secciones y tarjetas
